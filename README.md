## ⭐ Featured Projects

Selected strongest projects demonstrating technical complexity and originality:

### Negobuy
**Problem:** Businesses struggle to efficiently discover and negotiate with vendors, leading to higher costs and slower procurement cycles.  
**Solution:** Autonomous AI agent that discovers vendors, negotiates deals, compares offers, and enables smarter purchasing decisions.  
**Tech:** Python · AI · Automation · MIT License  
[GitHub](https://github.com/PsPrakulKomarla/Negobuy) · [Demo](https://github.com/PsPrakulKomarla/Negobuy)

### trueforge
**Problem:** Lack of standardized runtime layer for LLM agents – agents lack tool use, memory, and orchestration infrastructure.  
**Solution:** Framework providing the infrastructure for agent orchestration, tool use, lifecycle management, and semantic checkpoints.  
**Tech:** TypeScript · LLM Orchestration · MIT License  
[GitHub](https://github.com/PsPrakulKomarla/trueforge)

### Impact-Pilot
**Problem:** AI agents lose context across complex execution flows, causing failed tasks and lost progress.  
**Solution:** Plugin providing entity-level semantic checkpoints for maintaining context and enabling recovery across execution flows.  
**Tech:** C · Semantic Context · CLI Integration · MIT License  
[GitHub](https://github.com/PsPrakulKomarla/Impact-Pilot)

## 🎯 Animation Specifications (Hero Banner)

The animated hero banner (`assets/hero.gif`) features a **custom original animation** inspired by premium developer profiles, with these design principles:

### Visual Concept (Original — NOT copied from reference):

**Central AI SYSTEM CORE** — a glowing pulsating nucleus representing intelligent systems, surrounded by **6 autonomous system/agent nodes** representing:

1. **VISION** — computer vision / visual processing
2. **VOICE** — speech and audio processing  
3. **AGENTS** — LLM agent orchestration
4. **CODE** — software development and systems
5. **DATA** — data processing and pipelines
6. **SYSTEMS** — overall system architecture

### Animation Layers:

1. **Core pulse** — subtle glow pulsing at 2-second intervals
2. **Orbital rings** — 3 rings slowly rotating around the core
3. **Node movement** — 6 nodes orbiting the core at varying speeds
4. **Network connections** — lines connecting nodes to core, pulsing periodically
5. **Data particles** — minimal particles drifting through the scene
6. **HUD indicators** — subtle status lights changing intensity
7. **Light intensity** — gentle bloom/glow variation
8. **Optional parallax** — subtle camera movement effect

### Animation Parameters:

- **Duration:** 4-5 seconds per loop, seamless loop
- **Color scheme:** Near-black background, electric cyan, teal, violet accents, white/gray text
- **Style:** Dark futuristic cybernetic, minimal, cinematic, subtle
- **Frame rate:** 12-15 FPS (optimized for under 5 MB)
- **Resolution:** 1600 × 500 pixels (wide cinematic aspect ratio)
- **File size:** Under 5 MB (optimized — reduced frames, colors, resolution)
- **Looping:** Seamless — first and final frames visually connect

### What the Animation is NOT:

- ❌ Flashy or rapid
- ❌ Distracting or gaming-style
- ❌ Overloaded with particles
- ❌ Constantly flashing
- ❌ Generic AI brain or robot head imagery

### Viewer Experience:

The viewer should notice the animation after watching the profile for a few seconds. The animation is smooth, slow, cinematic, and subtle — it enhances the profile without distracting from the content.
